# Заметки по работе с Git в VS Code

## Что удобно делать в VS Code

1. Удобно видеть изменённые файлы во вкладке Source Control.
2. Можно быстро посмотреть различия между текущей и предыдущей версией файла.
3. Удобно создавать коммиты через интерфейс VS Code без необходимости вводить команды вручную.

## Что удобнее делать в терминале

В терминале удобнее просматривать историю коммитов с помощью команды `git log`, так как можно использовать дополнительные параметры и быстро получить нужную информацию.
